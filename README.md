# Problem Solving and Testing Using Java

This repository contains problem-solving solutions, lab assignments, and competitive programming tasks implemented in Java for the **Problem Solving and Testing Using Java** (PST) course.

---

## 📚 Repository Structure

| Directory | Topic / Focus | Problem Highlights |
| :--- | :--- | :--- |
| [**WEEK 1**](./WEEK%201/) | Arrays, Sorting & Comparators | Running Sum, Pivot Index, Lambda Expressions, Custom Comparators |
| [**WEEK 2**](./WEEK%202/) | Hashing, Deque & Subarrays | Maximum Subarray, Top K Frequent, Group Anagrams, Java Dequeue |
| [**WEEK 3**](./WEEK%203/) | Date/Time, Priority Queue & Sorting | Date/Time calculations, Priority Queue, Largest Number, Sort the People |
| [**WEEK 4**](./WEEK%204/) | String Validation & 2D Matrices | Halves Are Alike, Matrix Rotation, Diagonal Difference, Transpose Matrix |
| [**WEEK 5**](./WEEK%205/) | Advanced Subarrays & String Parsing | Circular Subarrays, String to Integer (atoi), Longest Substring, Pattern Matching |
| [**WEEK 6**](./WEEK%206/) | Advanced Strings & Palindromes | String Similarity (Z-algo), Longest Palindrome, Circular Palindromes, Anagrams |

## 🛠️ Languages & Tools

- **Language:** Java (JDK 8 / 11 / 17+)

- **Key Concepts:** Data Structures (Arrays, HashSets, HashMaps, Priority Queues, Deque), Algorithms (Kadane's, Sliding Window, Two Pointers, Z-Algorithm, Prefix Sums, Custom Comparators).
