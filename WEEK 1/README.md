# Week 1: Array Fundamentals, Sorting & Comparators

## 📋 Overview
This week focuses on introductory array manipulations, prefix sums, lambda expressions, and custom sorting techniques using `Comparator` in Java.

---

## 📂 Files & Problem Descriptions

| File | Source / Platform | Description |
| :--- | :--- | :--- |
| `Running Sum of 1d Array.txt` | LeetCode 1480 | Computes the running sum `runningSum[i] = sum(nums[0]…nums[i])`. |
| `Find Pivot Index.txt` | LeetCode 724 | Finds the index where the sum of numbers to the left equals the sum to the right. |
| `Richest Customer Wealth.txt` | LeetCode 1672 | Finds the maximum wealth among customers given a 2D account balance grid. |
| `Sort Array By Parity.txt` | LeetCode 905 | Rearranges an array so that even integers precede odd integers. |
| `Squares of a Sorted Array.txt` | LeetCode 977 | Returns an array of squares of each number sorted in non-decreasing order using two pointers. |
| `Comparator.txt` | HackerRank | Implements a custom `Checker` comparator for players based on score (descending) and name (ascending). |
| `Java Sort.txt` | HackerRank | Sorts a list of `Student` objects based on CGPA, first name, and ID. |
| `_lamda expressions.txt` | HackerRank | Implements lambda expressions for checking odd/even, prime numbers, and palindromes. |
