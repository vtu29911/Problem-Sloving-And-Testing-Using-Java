# Week 2: Arrays, Hashing, Subarrays & Deque

## 📋 Overview
This week focuses on hash tables, frequency counting, contiguous subarray analysis (Kadane's Algorithm), and double-ended queues (`Deque`) in Java.

| File | Source / Platform | Description |
