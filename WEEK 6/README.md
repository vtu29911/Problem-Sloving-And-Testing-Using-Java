# Week 6: Advanced String Algorithms, Palindromes & Pattern Matching

## 📋 Overview
This week covers advanced string manipulation, sliding window anagram detection, palindrome expansions, and linear-time pattern matching algorithms (Z-algorithm).

---

## 📂 Files & Problem Descriptions

| File | Source / Platform | Description |
| :--- | :--- | :--- |
| `Task 1 String Similarity (Week 6) (1).txt` | HackerRank | Computes the sum of lengths of longest common prefixes of $S$ and its suffixes using the **Z-Algorithm** ($O(N)$). |
| `Task 2 Repeated Substring Pattern (Week 6) (1).txt` | LeetCode 459 | Determines if a string can be formed by repeating a substring multiple times. |
| `Task 3 Two Strings (Week 6 (1).txt` | HackerRank | Checks if two strings share a common substring/character using bitmask/hash lookup. |
